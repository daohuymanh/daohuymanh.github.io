Tự động tạo video bài giảng từ PowerPoint và Word script bằng Python

2026.09.01 Cập nhật: 2026.09.01 11 phút đọc
Tác giả: Đào Huy Mạnh

Khi xây dựng khóa học e-learning, tài liệu đào tạo nội bộ hoặc video hướng dẫn, chúng ta thường đã có sẵn một file PowerPoint chứa nội dung trình bày và một file Word chứa lời thuyết minh cho từng slide. Thay vì thu âm thủ công rồi căn chỉnh từng slide bằng tay, bài viết này hướng dẫn xây dựng một công cụ Python miễn phí để tự động hoá toàn bộ quy trình, chỉ với một lệnh duy nhất.

1. Ý tưởng chung

Công cụ này dùng ba thành phần: Python để điều phối toàn bộ quy trình, Edge-TTS để sinh giọng đọc AI miễn phí, và FFmpeg để ghép ảnh slide với audio thành video. Luồng xử lý tổng quát như sau: 

PowerPoint + Script
        ↓
    AI Voice (Edge-TTS)
        ↓
    Video MP4
        ↓
    Subtitle SRT

Cụ thể hơn, mỗi slide trong PowerPoint được xuất ra thành một ảnh PNG, còn nội dung thuyết minh tương ứng được tách ra từ file Word theo từng đoạn "SLIDE n". Mỗi đoạn text này được Edge-TTS chuyển thành một file MP3, sau đó FFmpeg ghép từng cặp ảnh–audio lại thành một đoạn video ngắn, rồi nối toàn bộ các đoạn lại thành video hoàn chỉnh. Cuối cùng, chương trình tự sinh luôn file phụ đề SRT dựa trên thời lượng thực tế của từng đoạn audio. 

presentation.pptx          script.docx
        ↓                        ↓
  Xuất slide PNG          Tách nội dung theo slide
        └───────────┬───────────┘
                     ↓
                 Edge-TTS
                     ↓
      slide_1.mp3  slide_2.mp3  slide_3.mp3 ...
                     ↓
                  FFmpeg
                     ↓
      final_course.mp4  +  final_course.srt

Kết quả cuối cùng là một video có giọng đọc AI, slide tự chuyển theo đúng nhịp thuyết minh, và phụ đề đi kèm — có thể tải thẳng lên YouTube, Microsoft Stream, Moodle hay bất kỳ LMS nào, và người xem có thể bật/tắt Caption tuỳ ý vì phụ đề được lưu ở file riêng.

2. Chuẩn bị dữ liệu đầu vào

2.1. File PowerPoint

Ví dụ ở đây dùng file presentation.pptx. Xuất toàn bộ slide thành ảnh bằng PowerPoint: File → Save As → PNG → Every Slide. Kết quả sẽ là một thư mục ảnh: 

slides/
├── Slide1.PNG
├── Slide2.PNG
├── Slide3.PNG
└── ...

2.2. File script Word

File script.docx chứa lời thuyết minh, được đánh dấu theo từng slide bằng nhãn SLIDE n để chương trình ghép đúng nội dung với đúng slide. Ví dụ: 

SLIDE 1

Welcome everyone to this course.

SLIDE 2

In this lesson we will learn
the basic concepts of biosafety.

SLIDE 3

Let's begin with the first topic.
Lưu ý: nhãn SLIDE n phải viết đúng định dạng (không dấu, có khoảng trắng trước số) vì chương trình dùng regex để tách đoạn — sai định dạng sẽ khiến một slide bị gộp nhầm nội dung với slide kế bên.

2.3. Cấu trúc thư mục dự án

Course/
│
├── build_course.py
├── presentation.pptx
├── script.docx
│
└── slides/
    ├── Slide1.PNG
    ├── Slide2.PNG
    ├── Slide3.PNG
    └── ...

3. Cài đặt môi trường

Cài Python từ python.org, nhớ tick chọn Add Python to PATH lúc cài. Cài FFmpeg từ gyan.dev/ffmpeg/builds, rồi kiểm tra lại bằng: 

ffmpeg -version

Sau đó cài các thư viện Python cần thiết:

pip install edge-tts
pip install python-docx
pip install mutagen

4. Chạy chương trình

Sau khi đã có đủ file trong đúng cấu trúc thư mục, chỉ cần chạy:

python build_course.py

Chương trình sẽ tự động thực hiện tuần tự 5 bước:

  1. Đọc script từ script.docx, tách theo từng slide
  2. Sinh audio bằng Edge-TTS cho từng đoạn
  3. Ghép ảnh slide với audio tương ứng thành video ngắn
  4. Nối toàn bộ video ngắn lại thành một video hoàn chỉnh
  5. Sinh file phụ đề SRT dựa trên thời lượng audio thực tế

Kết quả đầu ra gồm:

audio/
video_parts/

final_course.mp4
final_course.srt

5. Mã nguồn — build_course.py

Toàn bộ logic nằm trong một file duy nhất, có thể tái sử dụng cho bất kỳ khóa học nào chỉ bằng cách thay presentation.pptx và script.docx rồi chạy lại. Phần cấu hình ở đầu file ( SCRIPT_FILE, SLIDES_DIR, VOICE, RATE...) là nơi chỉnh nhanh nhất nếu muốn đổi giọng đọc hay tốc độ nói.

Xem toàn bộ mã nguồn build_course.py 
import os
import re
import sys
import asyncio
import subprocess
from pathlib import Path

import edge_tts
from docx import Document
from mutagen.mp3 import MP3


# =====================================================
# CONFIG
# =====================================================

SCRIPT_FILE = "script.docx"

SLIDES_DIR = "slides"

AUDIO_DIR = "audio"

VIDEO_DIR = "video_parts"

FINAL_VIDEO = "final_course.mp4"

FINAL_SRT = "final_course.srt"

VOICE = "en-US-JennyNeural"

RATE = "+5%"

# Các giọng khác:
#
# en-US-JennyNeural
# en-US-GuyNeural
# en-GB-SoniaNeural
# en-GB-RyanNeural


# =====================================================
# HELPER
# =====================================================

def log(message):
    print(f"[INFO] {message}")


def fatal(message):
    print(f"[ERROR] {message}")
    sys.exit(1)


# =====================================================
# CHECK ENVIRONMENT
# =====================================================

def validate():

    if not os.path.exists(SCRIPT_FILE):
        fatal(f"Missing file: {SCRIPT_FILE}")

    if not os.path.exists(SLIDES_DIR):
        fatal(f"Missing folder: {SLIDES_DIR}")

    try:
        subprocess.run(
            ["ffmpeg", "-version"],
            stdout=subprocess.DEVNULL,
            stderr=subprocess.DEVNULL,
            check=True
        )
    except Exception:
        fatal("FFmpeg not found in PATH")


# =====================================================
# READ DOCX
# =====================================================

def extract_slide_scripts():

    log("Reading script.docx")

    doc = Document(SCRIPT_FILE)

    text = "\n".join(
        p.text.strip()
        for p in doc.paragraphs
        if p.text.strip()
    )

    slides = re.split(
        r"SLIDE\s+\d+",
        text,
        flags=re.IGNORECASE
    )

    slides = [
        s.strip()
        for s in slides
        if s.strip()
    ]

    if len(slides) == 0:
        fatal("No slide scripts found")

    log(f"Found {len(slides)} scripts")

    return slides


# =====================================================
# TTS
# =====================================================

async def generate_audio(slides):

    os.makedirs(AUDIO_DIR, exist_ok=True)

    total = len(slides)

    for idx, slide_text in enumerate(
            slides,
            start=1):

        mp3_file = os.path.join(
            AUDIO_DIR,
            f"slide_{idx}.mp3"
        )

        if os.path.exists(mp3_file):

            log(
                f"Skip audio slide {idx}"
            )

            continue

        log(
            f"TTS slide {idx}/{total}"
        )

        communicate = edge_tts.Communicate(
            text=slide_text,
            voice=VOICE,
            rate=RATE
        )

        await communicate.save(mp3_file)


# =====================================================
# GET SLIDE IMAGES
# =====================================================

def slide_num(filename):

    match = re.search(
        r'(\d+)',
        filename
    )

    if match:
        return int(match.group(1))

    return 999999


def get_slide_images():

    exts = (
        ".png",
        ".jpg",
        ".jpeg",
        ".bmp"
    )

    images = []

    for file in os.listdir(
            SLIDES_DIR):

        if file.lower().endswith(exts):
            images.append(file)

    images.sort(key=slide_num)

    if len(images) == 0:
        fatal("No slide images found")

    log(
        f"Found {len(images)} slide images"
    )

    return images


# =====================================================
# VIDEO PARTS
# =====================================================

def create_video_parts(images):

    os.makedirs(
        VIDEO_DIR,
        exist_ok=True
    )

    for idx, image_name in enumerate(
            images,
            start=1):

        image_path = os.path.join(
            SLIDES_DIR,
            image_name
        )

        audio_path = os.path.join(
            AUDIO_DIR,
            f"slide_{idx}.mp3"
        )

        if not os.path.exists(audio_path):

            print(
                f"[WARNING] Missing audio slide {idx}"
            )

            continue

        output_file = os.path.join(
            VIDEO_DIR,
            f"part_{idx}.mp4"
        )

        log(
            f"Creating video slide {idx}"
        )

        cmd = [
            "ffmpeg",
            "-y",

            "-loop", "1",

            "-i", image_path,

            "-i", audio_path,

            "-shortest",

            "-c:v", "libx264",
            "-preset", "medium",

            "-pix_fmt", "yuv420p",

            "-c:a", "aac",
            "-b:a", "192k",

            output_file
        ]

        subprocess.run(
            cmd,
            stdout=subprocess.DEVNULL,
            stderr=subprocess.DEVNULL
        )


# =====================================================
# MERGE
# =====================================================

def merge_videos():

    video_files = sorted(
        Path(VIDEO_DIR).glob(
            "part_*.mp4"
        ),
        key=lambda x:
        int(
            re.search(
                r'(\d+)',
                x.name
            ).group(1)
        )
    )

    if len(video_files) == 0:
        fatal("No video parts found")

    concat_file = "concat.txt"

    with open(
            concat_file,
            "w",
            encoding="utf-8") as f:

        for item in video_files:

            f.write(
                f"file '{item.as_posix()}'\n"
            )

    log("Merging final video")

    subprocess.run([
        "ffmpeg",
        "-y",
        "-f", "concat",
        "-safe", "0",
        "-i", concat_file,
        "-c", "copy",
        FINAL_VIDEO
    ])

    os.remove(concat_file)


# =====================================================
# SUBTITLE
# =====================================================

def format_time(seconds):

    hours = int(seconds // 3600)

    minutes = int(
        (seconds % 3600) // 60
    )

    secs = int(seconds % 60)

    millis = int(
        (seconds - int(seconds))
        * 1000
    )

    return (
        f"{hours:02}:"
        f"{minutes:02}:"
        f"{secs:02},"
        f"{millis:03}"
    )


def create_srt(slides):

    log("Creating subtitle file")

    current_time = 0.0

    subtitle_id = 1

    with open(
            FINAL_SRT,
            "w",
            encoding="utf-8") as srt:

        for idx, text in enumerate(
                slides,
                start=1):

            audio_file = os.path.join(
                AUDIO_DIR,
                f"slide_{idx}.mp3"
            )

            if not os.path.exists(
                    audio_file):
                continue

            audio = MP3(audio_file)

            duration = (
                audio.info.length
            )

            start = format_time(
                current_time
            )

            end = format_time(
                current_time + duration
            )

            clean_text = (
                text.replace("\n", " ")
                .replace("  ", " ")
                .strip()
            )

            srt.write(
                f"{subtitle_id}\n"
            )

            srt.write(
                f"{start} --> {end}\n"
            )

            srt.write(
                clean_text + "\n\n"
            )

            current_time += duration

            subtitle_id += 1

    log(
        f"Created {FINAL_SRT}"
    )


# =====================================================
# MAIN
# =====================================================

async def main():

    print()
    print("=" * 60)
    print("ONLINE COURSE VIDEO BUILDER")
    print("=" * 60)

    validate()

    slides_text = (
        extract_slide_scripts()
    )

    slide_images = (
        get_slide_images()
    )

    if len(slide_images) < len(slides_text):

        print()
        print(
            "[WARNING] "
            f"{len(slide_images)} slides "
            f"but {len(slides_text)} scripts"
        )
        print()

    await generate_audio(
        slides_text
    )

    create_video_parts(
        slide_images
    )

    merge_videos()

    create_srt(
        slides_text
    )

    print()
    print("=" * 60)
    print("FINISHED")
    print("=" * 60)

    print()
    print("Generated:")
    print(f" - {FINAL_VIDEO}")
    print(f" - {FINAL_SRT}")
    print()


if __name__ == "__main__":
    asyncio.run(main())

6. Đổi giọng đọc

Chỉ cần đổi giá trị hằng số VOICE ở đầu file. Một số lựa chọn thông dụng: 

# Tiếng Anh
en-US-JennyNeural
en-US-GuyNeural
en-GB-SoniaNeural
en-GB-RyanNeural

# Tiếng Việt
vi-VN-HoaiMyNeural
vi-VN-NamMinhNeural

7. Về phụ đề (SRT)

Chương trình sinh riêng file final_course.srt, không "đóng cứng" phụ đề vào hình video. Nhờ vậy người xem có thể bật/tắt Caption, chọn kích thước hiển thị, hoặc dùng tính năng dịch tự động trên YouTube — điều mà phụ đề hard-sub không làm được.

8. Hướng nâng cấp tiếp theo

  • Tự xuất slide trực tiếp từ PowerPoint bằng COM Automation, bỏ qua bước xuất PNG thủ công
  • Tự động upload video lên YouTube hoặc Microsoft Stream sau khi build xong
  • Sinh phụ đề theo từng câu thay vì theo cả slide, để phụ đề "chạy" mượt hơn
  • Dịch tự động lời thuyết minh sang nhiều ngôn ngữ
  • Tạo giọng đọc đa ngôn ngữ cho cùng một khóa học

9. Kết luận

Với Python, Edge-TTS và FFmpeg, ta có thể xây dựng một quy trình tạo video bài giảng hoàn toàn tự động, miễn phí và dễ mở rộng — chỉ cần chuẩn bị slide và script, rồi chạy python build_course.py là có ngay video kèm phụ đề. Cách làm này giúp tiết kiệm đáng kể thời gian sản xuất nội dung đào tạo, đồng thời đảm bảo tính nhất quán về giọng đọc và nhịp độ giữa các khóa học khác nhau.

Viết bài mới cho blog bằng Markdown (.md) và script tự động

2026.09.04 6 phút đọc
Tác giả: Đào Huy Mạnh

Thay vì gõ tay từng thẻ HTML cho mỗi bài viết mới, blog này dùng một script Python nhỏ: bạn chỉ cần viết nội dung bằng Markdown, script sẽ tự sinh ra file .html đúng định dạng và tự thêm card vào trang chủ.

Vì sao dùng Markdown thay vì gõ HTML tay

Gõ HTML tay cho mỗi bài viết dễ sai sót (quên đóng thẻ, lệch class, quên cập nhật index.html) và tốn thời gian. Markdown giải quyết việc đó:

  • Cú pháp ngắn gọn, quen thuộc (##, ```, -, >...)
  • Một thư viện chuẩn (markdown) lo phần chuyển đổi sang HTML, không cần tự viết trình phân tích cú pháp
  • Script tự lo luôn phần khung trang (header, footer, license) và tự chèn card vào trang chủ

Chuẩn bị file .md

Mỗi bài viết là 1 file .md, chia làm 2 phần: front matter (thông tin bài viết) và nội dung — ngăn cách bằng dòng ---.

Front matter cần đủ 8 trường sau:

Trường Ý nghĩa
title Tiêu đề bài viết
slug Tên file .html sẽ được tạo ra
tag Class CSS của chủ đề
tag_label Tên chủ đề hiển thị
date Ngày đăng
reading_time Thời gian đọc ước tính
author Tác giả
excerpt Mô tả ngắn hiện trên card

Giá trị tag phải là một trong 5 chủ đề đang có trên trang: tag--congdong, tag--tools, tag--miendich, tag--phantu, tag--thongtin.

Cú pháp Markdown được hỗ trợ

Phần nội dung phía dưới dòng --- hỗ trợ đầy đủ Markdown chuẩn:

  • Tiêu đề mục dùng ##
  • Đoạn văn: gõ bình thường, cách nhau bằng dòng trống
  • In đậm với **chữ**, in nghiêng với *chữ*
  • Gạch đầu dòng với -, danh sách đánh số với 1.
  • Khối trích dẫn / lưu ý với >
  • Khối code đặt trong cặp dấu ba backtick
  • Link dạng [chữ hiển thị](đường-dẫn)
  • Bảng dùng dấu | giữa các cột

Đoạn văn đầu tiên trong file luôn được script tách riêng ra làm đoạn mở đầu (lead), hiển thị to hơn các đoạn khác — không cần đánh dấu gì thêm.

Chạy script

Đứng tại thư mục gốc của repo trong Termux, chạy:

python3 new_post.py ten-bai-viet.md

Script sẽ:

  1. Đọc front matter và nội dung Markdown
  2. Sinh ra file .html đúng tên đặt ở slug, dùng đúng khung và style của trang
  3. Tự chèn card bài viết mới vào đầu danh sách trong index.html

Vì card mới luôn được chèn vào vị trí đầu tiên, và CSS của trang tự hiển thị card đầu tiên lớn hơn các card khác, bài mới nhất luôn hiện nổi bật nhất mà không cần chỉnh gì thêm.

Kiểm tra và đẩy lên GitHub

Trước khi push, nên xem qua kết quả:

git diff index.html

Nếu mọi thứ ổn, đẩy lên như bình thường:

git add .
git commit -m "thêm bài viết mới"
git push

Vì SSH key đã được cấu hình từ trước, bước git push sẽ chạy thẳng, không hỏi mật khẩu.
